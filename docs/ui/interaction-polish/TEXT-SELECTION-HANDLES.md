# 文本触摸选区端点

本项接续 S8 的文本短按、长按与多击。编辑和只读宿主共用把手的输入、绘制与滚动调度；实际选区继续由原宿主发布。键盘和 accessibility 使用原文本选择入口。

## 配置与显示

TextTouchOptions.selectionHandles 使用 TextSelectionHandleOptions：enabled 默认 true，radius 默认 6，hitRadius 默认 18，color 默认 None。半径有限且为正，命中半径不小于绘制半径；颜色须有限。未指定颜色时，编辑宿主使用 caretColor，只读宿主使用 selectionColor 的不透明颜色。

成功的触摸／笔短按、多击或长按显示把手；非空选区显示两个端点，折叠选区显示一个 caret 把手。鼠标、键盘、失焦、禁用、外部选区／正文或绑定变化及卸载撤下它们。显示状态不修改正文、历史或语义阅读顺序。关闭配置只关闭把手，短按、长按、多击和键盘／语义选择保持各自配置。

端点来自本次文本布局与真实方向选区，保留 affinity 和显示投影。把手位于 caret 下方，相邻端点向外分开；重叠命中带按两把手的中线分割。绘制和输入在同一 SceneContext 中放置，遵守当前完整 clip；根据本次场景的可见边界约束位置，不能使用上一帧的 viewport 尺寸替代。此动态几何计算不进入可直接重放的场景缓存。绘制半径与命中半径独立，命中不越过父裁剪。

## 接触与选区

两个把手区域是文本区域的非焦点子区域。只按下再抬起时不取得归属或阻止宿主短按，使二／三击仍然可用；移动达到文本触摸阈值后才 claimContacts 原触点，并取消宿主按压及滚动候选。按下即超过阈值为零的配置也须有实际位移。

拖动保存被调整的端点和另一个固定端点。原本折叠的 caret 把手移动两个端点；非空选区允许经过另一端点并反向，不在交叉时切换手指身份。指针与 caret 的初始窗口距离用于补偿抓取位置，避免从圆形把手按下时 caret 跳到手指下方。移动和最终释放使用当前 Accepted 几何及匹配正文／投影的布局命中，不能合成鼠标事件。

第二触点、被阻止的移动／结束、失效几何、系统取消和回调内修改／关闭都会收束候选、归属、滚动订阅和 deadline。取消保留已经发布的实际选区；之后的迟到输入不恢复旧操作。主动拖动的区域在端点交叉或折叠期间保持身份，避免因自己的选区更新而被当成目标卸载。

## 边缘滚动

两类宿主使用已有 Accepted 滚动路径，从内层视口向外尝试移动；只读文本借用父视口，编辑器包含自己的文本视口。指针靠近可见边界时使用一次性 16 ms deadline，按距离计算有界步长；无可消费余量即停止。滚动后等待新的 Accepted 帧，再按固定窗口指针重算文字落点，不用预测 offset 绘制或命中。

开始拖动时观察这条路径上的实际 ScrollState 定位意图。自己的边缘滚动继续操作，外部定位、换绑或路径失效取消旧操作；结束立即关闭这些订阅。把手只改变选区及真实滚动位置，滚动条、caret、文本 provider 与语义几何继续沿原宿主和当前场景发布。

## 验证

分别覆盖 caret、两个方向端点、交叉与折叠、grapheme／RTL／投影、编辑与只读、嵌套边缘滚动、结束后停帧及取消／重入。原短按、长按、多击、行内动作、鼠标和键盘组合必须继续通过。窗口输入与可见把手需实际验证，受控 native 队列不代替真实触屏／笔和读屏器验收。
