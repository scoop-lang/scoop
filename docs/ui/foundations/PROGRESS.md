## A1：场景几何与纯绘图块分离

Element 采用 `measure → scene`；SceneContext 控制共同的变换、clip、图层、输入区域和子项呈现，draw 块只借用隔离的 PaintContext／Canvas。场景操作同步消费，不保留跨帧借用。StylePainter、ParagraphHost、现有控件、相关示例及测试已直接迁移。尚未提供绘制缓存，省略 draw 的回归只验证输入不依赖像素块执行。
