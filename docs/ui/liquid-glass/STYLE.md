# Liquid Glass 独立主题

2026-11-28。本轮在已完成的玻璃材质与融合能力上交付第五套完整主题。验收限定本机 macOS arm64 release；普通库行为、原生交互、视觉和持续交互性能均需实际验证。

## 实施顺序与完成条件

1. 独立 `scoop.ui.style.liquidglass` Cone 与 `liquidGlassTheme`：完整明暗语义色、字体、几何、四类绘图部件、配置与偏好解析；普通消费者可直接构造并绘制。
2. 默认材质与表面策略：按控件和浮动表面的尺度设置光学参数，默认玻璃集中于操作、导航、工具栏和浮动层；正文及输入保留稳定底色。外部配色、局部清除和根偏好有明确优先级。
3. 全套组件外观：状态、选中、焦点和校验沿公共主题消费；密集内容、次要文字和复杂下层满足可读性，同时保留可见材质。必要公共扩展由真实组件调用驱动。
4. 实际布局融合：工具栏操作组和分段选择等组合使用实际子项测量轮廓，适应文字、换行、RTL、窄窗和文字缩放；稳定 key、独立输入和语义、动画中断、出现与移除均有明确行为。
5. Gallery 第五套 Style：完整页面及四个应用组合可切换；演示配置可继承主题默认策略或显式覆盖；同步开发 sysroot、API 文档、示例和编程材料。
6. 本平台统一验收与性能优化：持续滚动、形变、多表面及弹层负载保留优化前后可比较数据，检查帧间隔、主线程绘制时间和资源开销；闭合既有 Popover 键盘焦点会话，验证静止、隐藏及卸载停帧。

每大项完成后先格式化与检查，再运行相关验证、提交并推送。若发现编译器或底层库缺口，独立分支修复、PR 合并、更新 main 并合回工作分支、更新工具链后继续。原始性能记录和日志保存在仓库外。

## 性能方法

先用同一 release Gallery、窗口尺寸和工作负载记录基线。每个负载预热后持续提交有限帧，分别比较实体回退、玻璃滚动、形变与多表面。使用真正的场景绘制、原生帧提交和 Metal 呈现记录；绘制耗时不混同于 GPU 完成时间，CPU 采样只用于定位热点。优化保留当帧背景、清晰前景、输入几何及可访问性语义，不以关闭玻璃、降低交互频率或缓存过时背景作为性能达标手段。

## 验收记录

1. 独立主题：新增 Cone、完整明暗语义配色、字体／尺寸／动效与四类绘图部件。macOS arm64 release 的格式化、含测试的语义检查、两项构造／绘图／偏好／配置快照测试通过；开发 sysroot 已准备，`scoop doc --deny-doc-warnings` 与 `scoop-api show liquidGlassTheme` 已验证公开声明和 import。统一组件验收在后续阶段进行。
2. 材质与用途：按小操作、导航／工具栏、浮动层共享三组光学描述；Content／Input 保持实体。主题现有五项测试通过，新增覆盖用途独立配置、局部清除、偏好关闭与恢复，以及明暗主题 2× Raster 像素中的当前下层变化和清晰前景；开发 sysroot 已更新。Metal 与真实组件在后续统一验收。
