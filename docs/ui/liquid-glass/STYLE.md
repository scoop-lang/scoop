# Liquid Glass 独立主题

2026-11-28。本轮在已完成的玻璃材质与融合能力上交付第五套完整主题。验收限定本机 macOS arm64 release；普通库行为、原生交互、视觉和持续交互性能均需实际验证。

## 实施顺序与完成条件

1. 独立 `scoop.ui.style.liquidglass` Cone 与 `liquidGlassTheme`：完整明暗语义色、字体、几何、四类绘图部件、配置与偏好解析；普通消费者可直接构造并绘制。
2. 默认材质与表面策略：按控件和浮动表面的尺度设置光学参数，默认玻璃集中于操作、导航、工具栏和浮动层；正文及输入保留稳定底色。外部配色、局部清除和根偏好有明确优先级。
3. 全套组件外观：状态、选中、焦点和校验沿公共主题消费；密集内容、次要文字和复杂下层满足可读性，同时保留可见材质。必要公共扩展由真实组件调用驱动。
4. 实际布局融合：工具栏操作组和分段选择等组合使用实际子项测量轮廓，适应文字、换行、RTL、窄窗和文字缩放；稳定 key、独立输入和语义、动画中断、出现与移除均有明确行为。
5. Gallery 第五套 Style：完整页面及四个应用组合可切换；演示配置可继承主题默认策略或显式覆盖；同步开发 sysroot、API 文档、示例和编程材料。
6. 本平台统一验收与性能优化：持续滚动、形变、多表面及弹层负载保留优化前后可比较数据，检查帧间隔、主线程绘制时间和资源开销；闭合既有 Popover 键盘焦点会话，验证静止、隐藏及卸载停帧。

每大项完成后先格式化与检查，再运行相关验证、提交并推送。若发现编译器或底层库缺口，独立分支修复、PR 合并、更新 main 并合回工作分支、更新工具链后继续。原始性能记录和日志保存在仓库外。

## 性能方法

先用同一 release Gallery、窗口尺寸和工作负载记录基线。每个负载预热后持续提交有限帧，分别比较实体回退、玻璃滚动、形变与多表面。使用真正的场景绘制、原生帧提交和 Metal 呈现记录；绘制耗时不混同于 GPU 完成时间，CPU 采样只用于定位热点。优化保留当帧背景、清晰前景、输入几何及可访问性语义，不以关闭玻璃、降低交互频率或缓存过时背景作为性能达标手段。

## 验收记录

1. 独立主题：新增 Cone、完整明暗语义配色、字体／尺寸／动效与四类绘图部件。macOS arm64 release 的格式化、含测试的语义检查、两项构造／绘图／偏好／配置快照测试通过；开发 sysroot 已准备，`scoop doc --deny-doc-warnings` 与 `scoop-api show liquidGlassTheme` 已验证公开声明和 import。统一组件验收在后续阶段进行。
2. 材质与用途：按小操作、导航／工具栏、浮动层共享三组光学描述；Content／Input 保持实体。主题现有五项测试通过，新增覆盖用途独立配置、局部清除、偏好关闭与恢复，以及明暗主题 2× Raster 像素中的当前下层变化和清晰前景；开发 sysroot 已更新。Metal 与真实组件在后续统一验收。
3. 组件状态：透明变体不生成额外底板或投影，选中和状态采样保留表面，静止 Tab 使用语义次要文字。修正强调色按压与破坏性操作的实际对比度边界。组件 286 项、主题自身 5 项以及使用新主题的 3 个原生无障碍会话通过；包含真实按钮／编辑器／复合选择／模态边界的操作和状态、五套主题的高对比度及透明度解析、复杂下层上的可读性。各页及四个应用的视觉验收留在 Gallery 接入后。
4. 实际布局融合：GlassEffectContainer 支持实测 Flex／Wrap、item 的 FlexItemOptions、出现／退场与中途重现；ButtonGroup 共享一次材质并按压形变，默认 Tabs 保持一个移动且变宽的选中底板。289 个组件测试、5 个玻璃原生会话及 3 个无障碍会话通过，涵盖真实文字、RTL、窄宽度、字号、稳定 key、退场输入关闭、立即收束与停帧；像素检查确认按钮及融合桥只混合一次下层，Tabs 存在实测的移动和变宽中间帧。公开文档生成、GlassEffectLayout API 查询与开发 sysroot 更新通过。过程中修复了无效构造器签名展开默认值的编译器崩溃，独立 PR #270 已合并；前端／driver 共 2,260 个 Rust 测试及 21 个 CLI 用例通过，本地 main、功能分支和后续使用的 release 开发工具链已更新。
5. Gallery：第五套全局 Style 与桌面／UIKit 共用页面依赖已接入，默认继承主题用途，首次自定义保留现有选择并可恢复默认；新增实测 Wrap 的长标签、窄宽、增删项及 ButtonGroup／Tabs 示例。6 项模型测试和 7 个原生会话通过：全部 70 页在明亮宽窗与暗色窄窗 RTL 下共 140 组真实提交，四应用完成 173 个编辑、弹层、阅读与卸载阶段，另覆盖玻璃页 AX 操作、中文输入组合中换主题、选择和隐藏停帧。应用 release 构建、共用 Gallery API 文档及本地文档链接检查通过；五套主题及组件使用已更新的开发 sysroot。本阶段不扩展到 iOS 执行验收。
6. 本平台验收与性能：完成下述六负载的三轮前后对照和资源采样，减少重复配色解析与离屏滤镜准备；修正 Gallery 的 Narrow 将宽度约束施加给实际 Wrap 容器，并让背景裁剪到圆角。格式、含测试的 check、style 33 项、主题消费者 53 项、组件 289 项及 Liquid Glass 自身 5 项测试通过。优化后重新运行 5 个原生玻璃组件会话、完整 32 阶段 Popover 焦点会话和 7 个 Gallery 会话全部通过，保留全部交互、像素、语义、资源及停帧断言。最新 release Gallery 已实际启动，人工操作验证明暗、150% 字号、窄宽长标签、RTL、增删项、动作保持和 Tabs 底板；应用与开发 sysroot 均已重建。验收范围为本机 macOS，不扩展到其他平台的运行结论。

## 本机性能对照

Apple M3 Ultra（Mac15,14，512 GiB），macOS 27.2.1（26B131），1120 × 860 逻辑像素、2× DPI、60 Hz。优化前为第 5 项提交 `3be127877` 加相同的六项性能用例，优化后为第 6 项实现；两者均使用同一 release 工具链与符号选项。每项预热 24 帧，采集 120 帧；前后交替运行三轮，期间不编译或运行其他绘图验收。表内是三轮均值的中位数，单位 ms，记录主线程场景绘制耗时，不代表 GPU 完成时间。

| 负载 | 优化前 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| 实体回退滚动 | 2.972 | 2.900 | -2.4% |
| 玻璃滚动 | 3.019 | 2.961 | -1.9% |
| 持续融合形变 | 2.984 | 3.034 | +1.7% |
| 多用途玻璃表面 | 3.689 | 3.141 | -14.9% |
| 全局 Liquid Glass | 3.984 | 3.566 | -10.5% |
| 滚动、形变与弹层开合 | 0.958 | 0.889 | -7.2% |

多表面首次提交间隔的中位数从 55.3 降至 45.3 ms；全局主题从 54.7 降至 48.2 ms，对应首帧绘制从 14.0 降至 8.6 ms。每个版本稳定段共 2,160 帧：优化前没有超过 33.3 ms 的间隔，优化后在第二轮弹层负载出现一次 103.1 ms 间隔；其余稳定段没有超过 33.3 ms。优化后各负载三轮 P99 的中位数为 18.4–21.9 ms。冷启动首个提交约 155／160 ms，仍包括窗口、字体和 Metal 初始化；这些结果不构成每帧均为 60 FPS 或所有负载都加速的承诺。

使用 `proc_pid_rusage` 采样实际原生测试子进程，按 `mach_timebase_info` 换算 CPU 时间。完整六负载会话的 CPU 时间中位数为 9.64／9.43 秒，峰值 RSS 为 228.4／224.8 MiB，包含原生图形资源的 physical footprint 为 1,286.6／1,285.9 MiB；峰值内存基本持平。每次会话都通过停止交互后的暂停、无新帧请求、连续两次帧快照相等，以及卸载后 detached 的断言。

优化集中于避免布局测量重复解析完整材质配色、跳过已由局部背景覆盖的可读填充计算，以及仅在轮廓可能可见时创建／替换玻璃滤镜。已有滤镜直接复用，避免为稳定表面每帧增加裁剪查询。融合仍处理当帧下层；不缓存背景图像，不关闭玻璃或缩减交互频率。新增 Raster／Metal 像素与资源测试覆盖离屏后返回、裁剪边缘、融合桥、材质变化和不受装饰裁剪影响的前景。原始采样、各轮间隔、CPU profile 和日志均保存在仓库外。

## 原生外观校对

2026-11-28，在 `c199e19df` 上继续校对。参考用户提供的焦点环截图，实际打开 Finder 与“音乐”，观察搜索、工具栏、侧栏、分段选择、浮动播放器及音量弹层，并使用本机 AppKit 控件核对明暗焦点颜色。校对范围是当前 macOS 的控件层次与状态表达，不声称复刻所有系统应用的私有绘制。

- 焦点由深色细双线改为宽度／外扩均为 3.5 的贴边光环，保留系统配色自身的 alpha；输入内边框不再随焦点无条件染蓝。错误轮廓使用 2／2，与同色内边连续相接。新增 1×／2× Raster 测试覆盖明暗、错误、外部配色和可访问性偏好。
- 内容与输入使用中性底色，普通输入半径 8，操作按钮使用胶囊及 500 字重；取消不必要的常驻按钮投影。菜单、浮层、对话框及侧栏统一消费主题的对应圆角，选中侧栏使用中性底板，禁用文字保留明确衰减。
- Switch 的宽椭圆滑块、普通／小尺寸和 Slider 的白色滑块使用公共 `ThemeControlMetrics` 与 `controlThumb`；位置尊重 RTL 与字号缩放。滑块有独立 hover／press 反馈，键盘焦点不再由悬停代替；禁用轨道、高对比度、减少透明度与局部覆盖保持各自优先级。深色破坏性动作的按压文字对比度同步修正。
- 新增 `Theme.surfaceFocus(kind)`，复合控件共享已经解析根偏好的焦点描述，避免为了取焦点样式构造完整几何。协议包装消费者、规范、库 README、编程导航和生成 API 文档均同步。
- 修正禁用 Tooltip／HoverCard 会把包裹的正常控件也标为禁用的语义错误；禁用弹层只停用弹层动作。原生 AX 测试覆盖包裹的按钮组和勾选框，验证正常动作仍有效、子控件自己的禁用仍有效。Gallery 的 Popover 表单改用关联 FieldLabel，避免静态字段名进入 Tab 顺序，并提供真实朗读名称。

本轮通过 style 33 项、主题消费者 53 项、组件 293 项、Liquid Glass 8 项、原生玻璃组件 5 项、原生无障碍 3 项、Gallery 模型／配色／风格 7 项测试。Gallery 70 页在明亮宽窗与暗色窄窗 RTL 下完成 140 组提交，玻璃页原生会话通过。含测试的 check、release 应用构建、开发 sysroot、API 文档生成与公开声明查询通过。实窗核对了明暗输入焦点和错误边界、侧栏选择／禁用、Switch 切换与 RTL、Slider 键盘步进，以及 Popover 打开时的输入聚焦与圆角投影。最终构建确认 Width → Max. width → Height 每次只需一个 Tab，三个输入均有对应的 AX 名称，Escape 正常关闭弹层。

本轮完整 Popover 自动会话和两个 Slider 原生会话未通过：新产物停在阶段 0 的 `window.isFocused` 等待并超时；未改动的旧 Popover 产物也在阶段 3 等待前台焦点时超时。它们未被计入通过数，也未放宽断言；上文第 6 项的 32 阶段通过记录属于上一批提交。其他依赖该前台条件的完整键盘会话未重复计入本轮。手工 Gallery 操作已验证实际输入聚焦、滑条键盘步进及弹层打开，但不能替代完整自动会话覆盖。验收仍限定本机 macOS arm64。
