## 工作方式

- 工作分支：`codex/ui-tree`。完整大项实施后统一格式化、检查和定向测试，随后提交、推送、合并最新 `origin/main`。
- 编译器／底层库缺口使用从 main 建立的独立分支，完成验证、推送、PR 合并；更新本地 main、合并回 Tree 分支，并更新配套命令或开发 sysroot 后继续。
- 外部依赖优先复用 `~/repos/scoop-dep`；需要下载时设置 `https_proxy=http://192.168.2.106:10809`。原始日志留在仓库外，阶段完成后清理不再需要的临时文件。
