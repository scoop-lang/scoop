# 错误类型与变体

共 **816** 个错误/失败相关枚举，**4,901** 个变体。它们与文案模板重叠，不能相加得出诊断总数。枚举名筛选范围为 Error/Failure/Violation/Rejection 及其 Kind/Reason；普通数据枚举、诊断严重级别、错误码枚举和失败阶段枚举不计入。结构体错误包装的文案已列在各错误明细表，不能因此认为本表是全部 Rust 错误类型。
