# Tree 本地组合验收

使用一个真实 macOS 窗口，围绕同一应用模型验证一万条节点的行虚拟化、多列固定表头、横向定位、祖先整行吸顶、真实键盘导航、勾选与选择、F2／Escape、隐藏编辑列后的焦点回退、同级排序、RTL、变高行、过滤及切换单列。追加表头指针调宽、Escape 恢复、键盘调宽和手势中移除列，核对实际动作来源。每阶段等待动画与焦点请求收束。记录实际标题挂载与编辑控件 FocusHandle，检查吸顶沿用原实例、卸载完整结束资源。

正文上的横向滚轮进入外层水平视口，保持纵向位置。同一行挂载后动态开启拖放，单击仍激活一次，达到阈值后开始拖出且不误触点击；准备后的原生会话在窗口关闭时退休。完整 OS 拖入提交另由 Gallery 的 Tree 页面验证。

纯数据与尺寸算法测试位于所属组件 Cone 的 `tests/tree_*.scoop`；此处只验证必须由实际窗口、输入路由和 Accepted 帧组合确认的行为。使用本地 release 模式及配套的开发 sysroot／链接器运行 `scoop test`。
