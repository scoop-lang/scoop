## 运行

保存整个项目，在根目录执行：

```sh
scoop test --release .
scoop run --release . -- sample.txt
```

## 预期结果

测试通过；样例输入的 stdout 为：

```text
lines=2, scalars=4, utf8Bytes=6
```

空文件成功并输出三个 0。参数缺失退出 2；读文件失败或非法 UTF-8 退出 1，说明只写 stderr，stdout 为空。

## 关键说明

`main` 负责参数、读取和进程退出；`inspectText` 计算并返回含 Long 字段的 `TextReport`；`renderReport` 在最终边界格式化。测试直接调用计算和格式化函数，不为测试把内部 API 改为 public，也无需启动进程验证每一种文本组合。

行数规则是：空文本为 0，CR/LF/CRLF 分行，末尾换行不额外增加空行；一个换行自身构成一行。字节数和标量数分别保留。`Path.readText` 负责打开、读完和关闭文件；解析成功前不发布半份报告。

## 常见误用

不要在读取阶段把数值存成附带单位的字符串，再在计算阶段解析回来。报告格式改变时修改渲染测试；输入协议改变时修改计算测试。大文件流式处理有不同的内存约束，本例展示的是明确的整文件读取合同。
